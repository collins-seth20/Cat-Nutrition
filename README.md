# Cat Meal Formulator

A browser-only cat meal calculator based on the supplied nutrition workbook data. Open `index.html` locally or use the public GitHub Pages site. No server or build step is required.

The public copy contains no personal cat profiles or source workbooks. It uses the workbook's default food and nutrient entries. Ingredient calculations are not a substitute for a complete diet plan; have a veterinary nutritionist review homemade diets, and consider the FDA's raw pet food safety guidance.
