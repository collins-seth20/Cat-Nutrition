# Cat Meal Formulator

A browser-only cat meal calculator based on the supplied nutrition workbook data. Open `index.html` locally or use the public GitHub Pages site. No server or build step is required.

The public copy contains no personal cat profiles or source workbooks. The Collins ground-meat substitutions reuse matching raw nutrient rows from the workbook. They are ingredient options, not complete diets. Have a veterinary nutritionist review homemade diets, and consider the FDA's raw pet food safety guidance.
